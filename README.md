Crosstown — an original round-based tactical FPS on three.js 0.187.0: two teams (VANGUARD vs SYNDICATE), 5v5 with bots, freeze-time buy menu (7 weapons, armor, flashbangs), round economy with loss bonuses, bomb plant/defuse on two sites, recoil/spread that rewards stopping to aim, headshots, crouching, minimap, synthesized audio. Single-player vs bots, static ES modules, no build step.

## Run it

```sh
# any static file server pointed at game/, then open it in desktop Chrome
cd game && python3 -m http.server 8080   # or: node ../serve.ts
# open http://localhost:8080
```

WASD move · mouse aim · click fire · R reload · 1/2/3 weapons · G flashbang · B buy menu · E plant/defuse · Ctrl crouch · Space jump.
